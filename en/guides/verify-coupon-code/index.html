How to tell whether a discount code is real before you use it

Practical steps to check a code’s source, terms and validity, spot fake or expired codes, and what to do when a code fails at checkout.

Updated: 9 November 20263 min readBy the Kobon team

The short version

  • A trustworthy code has a clear source: the store itself, an approved partner programme, or an announced official campaign.
  • Read the terms before you copy it: minimum spend, maximum discount, eligible categories and countries, expiry.
  • Never hand over personal details on a third-party page to “unlock” a code. Codes go in the checkout on the store’s official site, nowhere else.
  • When a code fails, the reason is usually in the terms, not the code.

Why so many codes fail

Discount codes travel fast. They’re copied from site to site, shared in group chats, and left online months after they expire. Some were personal to begin with, issued to one customer or for a first order only, and the store shut them down once they leaked. The result is a checkout session spent pasting code after code. The fix isn’t trying more codes. It’s checking the source and terms before you start.

Step 1: Where did it come from?

The source tells you more than anything else:

  • The store itself: the offers page on its site or app, or an official email from the store.
  • An approved partner: sites and creators who work with the store under a formal agreement and get codes for their audience.
  • Banks and payment providers: joint campaigns, usually announced in both the bank’s app and the store’s site.

If you can’t trace a code to any of these, treat it as unconfirmed. At Kobon we only publish codes whose source we know.

Step 2: Read every term

Most “this code doesn’t work” moments come down to a condition nobody noticed. Before copying, check:

  1. Minimum spend. Does your basket clear the threshold after other discounts?
  2. Maximum discount. A “20% off” code capped at SAR 50 won’t give you 20% on a big order.
  3. Excluded categories and brands. Many codes skip electronics, certain brands or items already on sale.
  4. Country. A code issued for Saudi Arabia may not work in the UAE, and vice versa.
  5. Customer type. Some codes are for new customers, first orders, or app users only.
  6. Expiry. Some codes also stop working once a usage limit is reached, before the stated end date.

Step 3: Red flags

Be wary of a code, or a site, if you see any of these:

  • A discount that’s implausibly large on products the store rarely discounts.
  • A request to install an unknown app, or enter your phone number or card details, to “reveal” the code.
  • A link to a site that looks like the store but has a different address, even by one letter.
  • A countdown pushing you to buy now with no written terms at all.
  • No date, no conditions and no named company behind the offer.

The simple rule: a code goes into the coupon box at checkout on the store’s official site. It never needs anything else from you.

Step 4: Test it safely

Add items to your basket, enter the code before you confirm payment, and make sure the discount actually appears in the order summary for the amount you expected. If it’s smaller, check the maximum discount. If you get an error, read it. Stores usually say why: the code has expired, doesn’t cover these items, or the minimum hasn’t been met.

When a code doesn’t work

  1. Check the spelling and remove any stray spaces.
  2. Re-read the terms, especially country, minimum spend and categories.
  3. Try the app instead of the website, or the other way round, if the terms mention it.
  4. If the code came from Kobon, tell us via the contact page with the store, the code and your country. We’ll check it within one business day.

Sale price or code?

Sometimes the reduced price on the product page beats any code, and many stores won’t let you combine the two. Compare both: the sale price on its own, and the full price with the code applied. Pick whichever is lower once shipping is included.

In Saudi Arabia, if you want to confirm an advertised sale is licensed, the Ministry of Commerce lets you check discount licences through its document verification service.
