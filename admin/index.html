لوحة التحكم

عدّل المتاجر والعروض والمواسم من المتصفح، من غير كود. التعديلات تتحفظ على GitHub والموقع يتحدث خلال دقيقة أو اتنين.

تعديل المحتوى

سجّل دخولك بحساب GitHub اللي يملك المستودع ye7iaaaaa/ye7ia-site، واختار المستودع، وعدّل المتاجر أو العروض، واحفظ. بعد الحفظ GitHub Actions يعيد بناء الصفحات تلقائيًا.

فتح Pages CMS

  • المتاجر والأكواد: ملف البيانات الرئيسي للعروض.
  • الفئات: أسماء ووصف ونصائح الشراء.
  • المواسم: تواريخ الجمعة البيضاء ورمضان وغيرها.

أول مرة: GitHub هيطلب منك تصرّح لتطبيق Pages CMS على المستودع. كمان مرة واحدة: انقل ملف البناء من tools/github-build-workflow.yml إلى .github/workflows/build.yml من واجهة GitHub (Create new file) عشان الموقع يتحدث لوحده بعد كل حفظ. التحليلات (الزيارات والدول) من Cloudflare Web Analytics، مش من هنا.
